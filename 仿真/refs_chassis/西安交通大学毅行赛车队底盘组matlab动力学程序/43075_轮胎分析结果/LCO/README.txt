使用方法
--------
  MATLAB R2022a 或 R2025b，cd 到本文件夹，运行:
  >> LCO_analysis

  一个脚本完成: 加载数据 → 清洗 → 拟合 → 出图

拟合结果
--------
  Fy R² = 0.9986   RMSE = 54 N
  Mz R² = 0.9741   RMSE = 4.4 Nm
  模型: Pacejka MF5.2, 18参数 (Fy) + 25参数 (Mz)

主要结论
--------
  1. LCO 对 Camber (0°~4°) 几乎不敏感
  2. 胎压从 12psi 降到 10.5psi，峰值 μ 变化 <5%
  3. 12psi 下峰值 μ ≈ 2.5~2.7
