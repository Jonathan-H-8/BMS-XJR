# 一、项目介绍
动力电池组主要为前驱电机提供最高DC60V直流电，项目要求设计并搭建动力电池组，掌握运维技术，保证能量配置稳定，是油车混合动力系统的核心项目。
## 1.1 项目背景
25赛季车队作为传统燃油车组别参加比赛，只有后驱动力，但是我们也可以在围场中看到有部分强校已经设计或配置了混合动力系统，通过前驱动力补足直线加速或赛车过弯的性能要求。电池是动力系统的心脏，我们要解决的是如何提供稳定的电压以及经济的使用电能，能量的分配和监管是项目的核心。完成混合动力系统储能装置HSC（Hybrid Storage Container），混合动力监控系统，一般为HSC的电池管理系统或电池保护电路 HMS（Hybrid Monitoring System）

那么我们的工作就集中在了能量监管和控制，包括了电能的输出和回收，也就是BMS。而电池包我们还没有确定加工商，必要时需考虑自主完成，日置曾有过联系，可以考虑。这里的问题在于我们没有前期研发的经验，所以大家都是从零开始，会有较大的难度，但是会有很大的收获，对车队电气化尤为重要，同时鉴于混合动力系统上线的期望时间在2027赛季，我们有较长的时间准备与迭代。

本项目申报有一项2026年省级大创项目背书，具有科研转化潜力，后期会附上大创结果。
